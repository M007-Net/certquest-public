# Practical lab outlines

Every main map topic now has a lab outline: 39 total across Foundations and the eight certification tracks. Open a landmark and select **Open practical lab**, or use **Coverage & labs** for the current track's list.

Each outline includes a goal, estimated time, setup, checklist, success criteria, evidence guidance, cleanup, and a stretch task. Paper/simulation options are identified in the setup. Cloud labs use design work or calculators and do not require paid deployments. The outlines are not automatically executed or graded.

Notebook notes and checked steps save in the existing browser save, including export/import. Self-recorded completion does not grant quiz mastery, equipment, or certification credit. Existing branch lab notes remain separate and intact.

Edit `scripts/build-domain-labs.py` and run it to regenerate `content/domain-labs.json` and `dist/domain-lab-data.js`. Runtime UI and validation live in `dist/domain-labs.js`. Run `npm test` after changes.
